## 1. Purpose

Any independent researcher must be able to reproduce the DataSciBench evaluation on this
project's Spec branch: discover → install → run the 45-task adapter evaluation → inspect
`raw_runs.json` → regenerate the Phase F tables/figures from raw → see the honest verdict.
Everything below is clone + commands; nothing requires an account except the *GT-lane* step
which is explicitly gated (§26 honesty — execution lane needs no GT, score lane does).

## 4. Reproduce (commands)

```bash
# 0. clone the Spec branch and install
git clone https://github.com/Jackxiaozhiren/data-science-agent.git
uv sync --dev                          # Python 3.12
.venv/bin/dsa doctor --json            # LLM warn is expected (deterministic pipeline, no key)

# 1. prepare the upstream benchmark workspace (operator step, pinned commit, no redistribution)
mkdir -p benchmarks/external/datascibench/.workspace
curl -L https://codeload.github.com/THUDM/DataSciBench/tar.gz/84ef3d4d94d7362a5149cf14a73dc168fc4f2f33 \
  | tar xz --strip-components=1 -C benchmarks/external/datascibench/.workspace
printf '%s\n' '84ef3d4d94d7362a5149cf14a73dc168fc4f2f33' \
  > benchmarks/external/datascibench/.workspace/.upstream_commit

# 2. run the full 45-task evaluation (execution lane, no GT)
DSC_WORKSPACE="$PWD/benchmarks/external/datascibench/.workspace" \
  .venv/bin/python benchmarks/external/datascibench/run_eval.py
# → writes benchmarks/external/datascibench/results/raw_runs.json

# 3. regenerate all Phase F artifacts from raw
.venv/bin/python research/v4_3/generate_phase_f_results.py
# → research/v4_3/results/{processed,tables,figures,manifests}/

# 4. tests for the adapter layer
.venv/bin/python -m pytest tests/evals/test_external_benchmark.py tests/evals/test_datascibench_adapter.py -q
```

## 6. Integrity / license notes

- **No upstream redistribution:** only the pinned tarball + gated GT, never vendored (§23).
- **No gold in agent view:** `AgentTaskView` + `assert_gold_isolation` (§19); verified by the
  adapter's integrity tests.
- **Original evaluator untouched:** adapter converts DSA output to the upstream `logs.txt`
  layout; evaluator subprocess wiring lands with the GT lane (manifest records this).
- **Hash discipline:** `raw_runs.json` is generated by `run_eval.py`; every Phase F artifact
  by `generate_phase_f_results.py`. No hand-edited numbers (§48).
