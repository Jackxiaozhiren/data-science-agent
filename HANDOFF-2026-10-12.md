Environment traps that have cost time here: zsh aborts a whole compound command on an unquoted glob,
so quote `--include='*.py'`; a pipeline reports only its last stage, so read `${pipestatus[1]}`;
there is no bare `python`, only `python3`; `uv run pytest -q --cov` does **not** print the pass count,
so use `uv run --frozen python -m pytest -o addopts="--asyncio-mode=auto" -q` when you need the number;
`ruff format` on a `.json` path exits 0 and corrupts the file; and `gh run list --commit` needs a full
SHA, and its `.[0]` row can be any of the three workflows a push starts — name the workflow or poll the
run id, and cross-check `commits/<sha>/status`.
