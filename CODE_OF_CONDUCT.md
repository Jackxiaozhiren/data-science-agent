# Code of Conduct

Be respectful. Follow MIT License. Enforce via GitHub issue moderation; violations may lead to temporary or permanent bans by maintainers.

- Treat all contributors with respect regardless of background.
- No harassment, discrimination, or unwelcome conduct.
- Report issues via GitHub Issues (or privately via `SECURITY.md` for security-sensitive conduct).

This is a lightweight CoC for a research codebase; PRs that only add `CODE_OF_CONDUCT` boilerplate without a real community need no further process.
